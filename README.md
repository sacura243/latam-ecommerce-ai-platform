# 拉美电商 AI 中台

前端公网地址：<https://sacura243.github.io/latam-ecommerce-ai-platform/>

## 当前能力

- 墨西哥店铺工作台、选品雷达、商品利润和库存
- 商品同步后自动带入商品素材
- 一键生成商品分析、脚本、分镜、配音和视频
- 素材库混剪 / AI 直接生成两种模式
- 独立接口中心和后端异步任务状态

## 正式接入

静态网页不能安全保存第三方密钥。请部署 `server/` 后端，填写环境变量，再把后端公网地址填入网页的“接口中心”。详细说明见 [server/README.md](server/README.md)。

## 本地管理配置

接口中心支持两种模式：

- 本地直连：适合个人电脑调试，可填写 Seedance/Seedream、OpenAI 兼容 LLM、Qwen3-TTS-VC、EasySpider RPA 的 Base URL、API Key 和模型参数。密钥会保存在当前浏览器本地存储，只适合本机或内网使用。
- 后端代理：适合公开网址。前端只填写后端地址，第三方密钥放入 `server/.env` 或部署平台环境变量。

首次打开会创建本地管理员账号。头像菜单可以退出登录或重置本机管理员和接口配置。这个管理员只保护当前浏览器界面，不是服务器鉴权。

## 商品内容工厂方向

参考批量商品内容工具的工作流，后续可以把商品目录扫描、TXT/图片知识库、批量任务队列和 Seedance 生成结果接入生产工作台。当前版本保留商品同步后自动带入素材的设计，不会伪造外部平台或视频服务的成功结果。
