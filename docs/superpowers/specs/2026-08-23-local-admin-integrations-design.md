# 本地管理员与接口配置设计

## 目标
让本地运行的拉美电商 AI 中台可以在“管理配置”中填写 Seedance/Seedream、LLM、TTS、EasySpider RPA 的连接信息，并用本地管理员门禁保护操作界面，同时保留后端代理模式供公开部署使用。

## 边界与安全说明
- 本地直连模式适合个人电脑或内网演示，API Key 会保存在浏览器本地存储并可被前端读取。
- 本地管理员只保护当前浏览器界面，不等同于服务端鉴权，也不能保护已经下发到浏览器的密钥。
- 后端模式下，前端只保存后端 URL，第三方密钥继续放在服务器环境变量中。
- 不在代码、Git 历史或示例配置中写入真实密钥。

## 页面设计
接口中心采用 WorkBuddy 风格的紧凑双列配置卡，移动端单列。卡片分为：运行模式、Seedance/Seedream、LLM 文案、Qwen3-TTS-VC、EasySpider RPA、后端连接。每张服务卡提供 Base URL、API Key/Token、模型或音色字段和测试按钮；保存按钮统一写入 `latam-integrations-v2`。

## 数据流
- `direct` 模式：商品同步、脚本生成、TTS、视频生成和 RPA 发布从统一配置读取 URL 与密钥，使用浏览器 `fetch` 调用；没有配置时显示明确的演示/待配置状态。
- `backend` 模式：沿用现有 `/api/products`、`/api/production`、任务轮询和发布接口。
- 生产任务保持现有“素材库混剪 / AI 直接生成”选择，服务错误只更新任务状态并通过 toast 告知，不伪造成功结果。

## 管理员门禁
- 首次打开显示“创建本地管理员”表单；用户名和密码经 Web Crypto SHA-256 哈希后保存，仅保存哈希和登录标记。
- 后续打开显示登录表单；头像菜单提供退出登录。
- 提供“重置本机管理员”入口，清除本地认证和本地接口配置，避免误以为可远程恢复。

## 验收标准
1. 未登录不能看到工作台内容；首次设置后刷新仍要求登录。
2. 管理配置可保存并回显四组服务字段、运行模式和后端地址。
3. 桌面端为双列卡片，390px 移动端为单列且无横向溢出。
4. 直连模式缺少配置时给出可理解的错误；后端模式原有流程不回归。
5. `node --check app.js`、`node --check server/server.js` 通过，浏览器手测登录、保存、退出和模式切换。
